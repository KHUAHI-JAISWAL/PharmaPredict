# PharmaLens-AI 💊
**Pharmaceutical Consumption Forecasting & Inventory Analytics**

PharmaLens-AI analyzes medicine consumption, inventory levels, and stockout patterns using data analytics and machine learning.

### 🛠️ Tech Stack
- Python, Pandas, NumPy
- PostgreSQL, SQL
- Scikit-learn
- Power BI

### 📊 Dataset
- **Source:** [Dryad Repository](https://doi.org/10.5061/dryad.h9w0vt4tw)
- **Records:** 457,225
- **Coverage:** 36 medicines and 16 districts in the current analysis

### ✨ Key Features
- Cleaned and analyzed pharmaceutical consumption data.
- Used SQL to identify consumption trends and inventory risks.
- Built a Random Forest model for medicine demand forecasting.
- Created a Power BI dashboard for consumption and stockout analysis.

### 📈 Model Results
- **MAE:** 9,442.15
- **RMSE:** 12,668.38
- **R²:** 0.134

*The forecasting model is experimental and requires further improvement.*

### 🎯 Objective
To support pharmaceutical inventory monitoring and data-driven medicine demand planning.
